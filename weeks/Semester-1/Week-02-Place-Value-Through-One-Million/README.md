## FIKR routine for this week (do not change the math)

**Learning Leading to Production. Content at home; thinking in class; evidence on the wall.**

| Stage | Time | What you do |
|---|---|---|
| **0 Preparation** | Before class | Compress tomorrow's lesson: I can... + one Visual Learning example (3-5 min video or 1 page). LMS. |
| **1 Diagnose** | 5-8 min | Niyyah (Iqra box). 2-4 items from Do You Understand? Gap map, not a grade. |
| **2 Knowledge Building** | 15-20 min | Close only flagged gaps. Think aloud on Visual Learning Bridge (a richer live example, not the homework clip). Convince Me! |
| **3 Practice** | 10-15 min | 2 guided Do You Know How? → 4 Independent items. Feedback in seconds. Amanah before self-mark. |
| **4 Production** | 10-15 min | One Problem Solving / HOT item not used in practice. New situation. AI = critic, never author. |
| **5 Mastery Gate** | 5-8 min | One Assessment Practice item, individual. Routes clinic or enrich. |
| **6 Smart Production** | 5-8 min | Signed product (3-line explanation / labelled diagram). Name on it. Muhasabah. Salam. |

**Essential Questions:** How are greater numbers written? How can whole numbers be compared? How are place values related?
