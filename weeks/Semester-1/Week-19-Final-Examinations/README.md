## More from the week file

### Standards / Skills Checklist

- Students should be able to:
- Place value & rounding
- Read, write, and represent numbers through 1,000,000
- Explain that a digit is 10 times the value of the same digit one place to the right
- Compare whole numbers using place value
- Round whole numbers to any place

- Addition & subtraction
- Add and subtract multi-digit whole numbers using the standard algorithm
- Subtract across zeros
- Use mental math (compensation, properties) and estimation
- Check reasonableness with estimates and inverse operations

- Multiplication
### Suggested Exam Structure

- Place value, rounding, add/subtract, 1-digit and 2-digit multiplication, 1-digit division with remainders.
- Area models, partial products/quotients, bar diagrams, factor arrays, equivalent-fraction models.
- Multi-step word problems, comparison, remainder interpretation, constructed arguments.
- Part D - Performance task (optional, in class) One extended task in the style of the Topic Performance Tasks (video-game scores, wooden beads inventory, classroom computers, candle fundraiser, saving to buy items, ski jumping, arranging vehicles).
### Administration Notes

- Allow grid paper, number lines, and place-value charts as permitted tools.
- Remind students to estimate first and to label answers with units.
- For constructed-response items, score for: correct math, clear representation, and a complete explanation.
- After the exam: record item analysis against the checklist above to plan Semester 2 intervention.

### After the Exam

- Collect Interactive Student Editions / workbooks for Volume 1.
- Preview Semester 2: Topic 8 remainder (if needed) then Topics 9-16 (fractions operations, line plots, decimals, measurement, patterns, angles, shapes).
- Celebrate growth: fluency paths, 3-Act Math, and STEM projects from Semester 1.
