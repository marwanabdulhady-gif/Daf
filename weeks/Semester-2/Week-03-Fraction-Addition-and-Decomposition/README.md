### Topic 9 Opening (p. 329)

- - from Morse code to the language of the Quran
- Morse code uses dots and dashes. Write Iqra, Jeddah, and DAF in Morse (or research how Arabs first sent telegrams).
- Write a short word in Morse. What fraction of the symbols are dashes?
- Write another word. What fraction are dots?
- Equation: how much greater is one fraction than the other?
- Iqra: we use codes and numbers to carry truth honestly.

### Week 03 Notes

- Like denominators: add numerators, keep the denominator. Never add denominators.
- Decompose in many ways - unit fractions or mixed chunks.
- Sums ≥ 1 → mixed numbers.
