## More from the week file

### Optional Bridge - Lesson 9-4 Model Subtraction (p. 345)

- Ustadh Yasser uses 1/8 of a sheet of plywood. How much is left? 8/8 − 1/8 = 7/8.
- Flower garden in eighths: 3/8 yellow roses. Fraction left: 8/8 − 3/8 = 5/8.
- Separating parts of the same whole. Difference as a fraction or mixed number (e.g., 11/8 − 2/8 = 9/8 = 1 1/8).
### Week 04 Notes

- Subtract: related addition or "numerator minus numerator."
- Number line: right = add, left = subtract; denominator = how many equal jumps in 1.
- Mixed numbers: add/subtract fractions first, regroup 1 = d/d when needed.
