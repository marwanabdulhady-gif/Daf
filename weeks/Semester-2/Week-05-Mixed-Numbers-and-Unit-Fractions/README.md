## More from the week file

### Topic 10 Opening (p. 381)

- Extend Multiplication Concepts to Fractions
- How can you describe a fraction using a unit fraction? How can you multiply a fraction by a whole number?
- - transparent / translucent / opaque. Suppose 1/3 of each of 5 same-sized posters is covered. What fraction of the posters are NOT covered? Use multiplication.
- - mixed number, equivalent fractions, unit fractions as copies.
- Design with tiles · Set up a charity event.
### Week 05 Notes

- Mixed-number addition: properties (break apart) or improper fractions.
- Subtraction: regroup 1 = d/d when the fraction being subtracted is larger.
- 3/4 = 3 × 1/4 is the bridge to whole number × fraction next week.
