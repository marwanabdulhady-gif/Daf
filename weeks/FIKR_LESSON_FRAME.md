# FIKR Model — How Grade 4 Math Lessons Run  
**Dar Al Fikr Boys School · Learning Leading to Production**  
Source: Trainee Guide (Dr. Aysar Shafiq Alomari, Excellence & PD Unit 2026–27)

**Core principle:** A lesson is not measured by what was taught. It is measured by what the boy can **show he made** from it.

**Adab layer (unchanged):** Niyyah from the Iqra box at the start of Diagnose. Muhasabah after Smart Production. Amanah on every self-mark. AI = **critic only, never author.**

**Do not change** any number, example, or problem in the week files. This frame only **assigns** existing parts to stages.

---

## The seven stages (enVision → FIKR)

| # | Stage | Time | Goal | What you use from the printed lesson |
|---|--------|------|------|--------------------------------------|
| **0** | **Preparation** | Before class | First exposure at home | Compress **I can…** + **one** Visual Learning example into a 3–5 min video or 1-page brief. Send via LMS. 4–5 check questions. |
| **1** | **Intelligent Diagnose** | 5–8 min | Gap map, not a grade | 2–4 items from **Do You Understand?** / Review. Kahoot/Quizizz/oral. Decide: 3-min re-teach or straight to modeling. |
| **2** | **Knowledge Building** | 15–20 min | Close flagged gaps, then model **one richer** example thinking out loud | Re-teach only what the gap map showed. Live model = **Visual Learning Bridge** (a **new** example, not the homework video). **Convince Me!** = two boys restate a step. |
| **3** | **Practice** | 10–15 min | Guided → independent; feedback in seconds | **Guided:** 2 identical **Do You Know How?** items. **Independent:** 4 items from **Independent Practice**. Instant check. Micro-conference 2 min if flagged. ~80% guided before release. |
| **4** | **Production** | 10–15 min | Genuinely **new** situation; first draft | One **Problem Solving** / HOT / STEM item **not** used in practice. Boy produces. **AI critic only** (see prompt below). You circulate; you do not give answers. |
| **5** | **Mastery Gate** | 5–8 min | One individual task that **routes** the next path | One **Assessment Practice** item (or last unused Independent item). No notes, no partner. Forward **or** clinic. Log mastery. |
| **6** | **Smart Production** | 5–8 min | A product he will **put his name on** | 3–5 line signed explanation, labelled bar diagram, or mini poster of **today’s** method. Wall / LMS / journal. Originality + reasoning, not only correctness. |

**40-minute period:** 5 + 12 + 8 + 8 + 4 + 3 (trim Production and Smart Production).  
**60-minute period:** use the full times above.

**Content at home** (0) → **thinking in class** (1–4) → **evidence on the wall** (5–6).

---

## AI critic prompt (Stage 4 — boys paste their own work)

> Do not solve this. Do not give the answer.  
> I am a Grade 4 boy. Here is my work: [paste].  
> Ask me **three questions** that check whether my reasoning is complete and honest (*amanah*).  
> Tell me if my explanation would convince a classmate. Do not rewrite my solution.

Teacher spot-checks that the guardrail held.

## Routing after the Mastery Gate (Stage 5)

| Result | Next path |
|--------|-----------|
| Secure | Enrichment: unused HOT / Pick a Project shard |
| Not yet | 2-minute clinic on the **same** Visual Learning model (not a new lecture) |

## Adab inside FIKR (not a second clock)

- **Niyyah:** first 20 seconds of Diagnose (Iqra box).  
- **Sabr:** named during Practice and Production.  
- **Amanah:** honesty line before any self-mark in Practice.  
- **Sitr:** private micro-conference, never public shame.  
- **Muhasabah:** last 30–60 seconds after Smart Production.

## Teacher prep (the night before) — 10 minutes

1. Open **today’s lesson only** in `week-XX.md`.  
2. **Stage 0:** already sent yesterday; prepare **tomorrow’s** 1-pager/video.  
3. Highlight: 3 diagnose items · the Visual Learning example you will model live · 2 guided + 4 independent · 1 Production item · 1 Gate item.  
4. Write the signed-product sentence for Stage 6 (“I can show ___ because ___.”).  
5. Do **not** rewrite numbers.

## Week types

| Week | How FIKR flexes |
|------|------------------|
| Teaching weeks | One FIKR cycle **per lesson** (usually 2–3 lessons / week). |
| Week 01 orientation | Stage 0 = Iqra + آداب. Diagnose = Review What You Know as printed. Production = STEM journal. Gate = diagnostic checkpoint. Smart Production = signed آداب poster. |
| Revision (17–18) | Stage 0 = mixed Must-know page. Diagnose = 4 mixed items. Building = one error-analysis model. Practice = Quick Practice. Production = one multi-topic item. Gate = 1 unused item. Smart Production = signed “my method” card. |
| Exams (19) | Stage 0 = checklist at home. Diagnose = 3 warm items (not scored). Building = none (or 5-min reminder). Practice = none. Production / Gate = the exam as printed. Smart Production = *alhamdulillah* + papers named. |
