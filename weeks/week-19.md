## Standards / Skills Checklist

Students should be able to:

### Place value & rounding
- [ ] Read, write, and represent numbers through 1,000,000
- [ ] Explain that a digit is 10 times the value of the same digit one place to the right
- [ ] Compare whole numbers using place value
- [ ] Round whole numbers to any place

### Addition & subtraction
- [ ] Add and subtract multi-digit whole numbers using the standard algorithm
- [ ] Subtract across zeros
- [ ] Use mental math (compensation, properties) and estimation
- [ ] Check reasonableness with estimates and inverse operations

### Multiplication
- [ ] Multiply 1-digit × multi-digit using arrays, area models, partial products, and properties
- [ ] Multiply 2-digit × 2-digit using area models and the Distributive Property
- [ ] Multiply by multiples of 10, 100, and 1,000
- [ ] Estimate products (rounding and compatible numbers)

### Division
- [ ] Find whole-number quotients with 1-digit divisors (mental math, partial quotients, sharing)
- [ ] Estimate quotients with compatible numbers
- [ ] Interpret remainders in context

### Problem solving
- [ ] Solve multiplicative and additive comparison problems
- [ ] Solve multi-step word problems with hidden questions
- [ ] Represent with bar diagrams, equations, and variables
- [ ] Make sense and persevere; construct arguments

### Factors, multiples, fractions
- [ ] Find all factor pairs; identify prime and composite numbers
- [ ] Find multiples of a given whole number
- [ ] Recognize and generate equivalent fractions (models, number lines, × or ÷ by *n/n*)
- [ ] Compare fractions using benchmarks and common denominators

## Suggested Exam Structure

**Part A — Computation (no calculator)**  
Place value, rounding, add/subtract, 1-digit and 2-digit multiplication, 1-digit division with remainders.

**Part B — Concepts & representations**  
Area models, partial products/quotients, bar diagrams, factor arrays, equivalent-fraction models.

**Part C — Problem solving**  
Multi-step word problems, comparison, remainder interpretation, constructed arguments.

**Part D — Performance task (optional, in class)**  
One extended task in the style of the Topic Performance Tasks (video-game scores, wooden beads inventory, classroom computers, candle fundraiser, saving to buy items, ski jumping, arranging vehicles).
