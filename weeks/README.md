# Grade 4 Mathematics — Weekly Curriculum Distribution (2026 - 2027)

Organized by Semester and Week according to the Math Department Curriculum Distribution for Academic Year **2026 - 2027**:

- **[Semester 1 (2026 - 2027)](./Semester-1)**: Weeks 1 to 19 (Place value, Addition/Subtraction, Multiplication, Division, Factors, Equivalent Fractions)
- **[Semester 2 (2026 - 2027)](./Semester-2)**: Weeks 1 to 19 (Fractions, Decimals, Measurement, Patterns, Geometry & Angles)

## These folders are the teaching copies

The decks in `Semester-1/Week-NN-…` and `Semester-2/Week-NN-…` are not plain copies of `html/`: each one carries that week's own page from the week file in this folder (`week-02.md` = Semester 1, `S2 week-01 (2).md` = Semester 2) as extra slides — the *I can…* statement, the Essential Question, Solve & Share, the Visual Learning Bridge with **Convince Me!**, the Another Example, the guided / independent runs, the Problem Solving page, Assessment Practice and the homework line, each with the model drawn from the printed numbers. Weeks that teach no numbered lesson get their own deck (`week-NN-*.html`).

Rebuild after editing a week file: `./rebuild-all.sh` (it runs `scripts/extract-week-content.js`, `scripts/stamp-weeks.js` and `scripts/build-week-decks.js` for you). Check the copy with `npm run check:weeks`.
