### Solve & Share

A manufacturer in Jubail produces three new cars that weigh 6,127 pounds, 4,652 pounds, and 3,393 pounds. If these are loaded on a truck, has the truck reached its 15,000-pound maximum? Use an estimate to decide. Solve this problem any way you choose.

**Look Back!** Why can you solve the problem using only an estimate rather than finding the exact weight of the three cars?

### Essential Question

How can you estimate sums and differences?

### Visual Learning Bridge

Books, magazines, and movies were checked out of the public library. About how many more books were checked out than magazines and movies combined?

12,642 books, 4,298 magazines, and 2,149 movies are checked out.

**Estimate: Round to the nearest thousand.**

Magazines and movies: 4,298 → 4,000; 2,149 → 2,000; sum = 6,000  
Books: 12,642 → 13,000  
13,000 − 6,000 = **7,000**  
About 7,000 more books were checked out.

**Estimate: Round to the nearest hundred.**

4,298 → 4,300; 2,149 → 2,100; sum = 6,400  
12,642 → 12,600  
12,600 − 6,400 = **6,200**  
About 6,200 more books were checked out.

**Convince Me!** Construct Arguments: The head librarian says she will establish a separate checkout desk for magazines and movies if the difference between the number of books and the number of these other materials is greater than 6,500. Which of the estimates above should you use to help her make her decision? Explain.

### Another Example

Decide if each computation is reasonable.

You can use an estimate to decide whether or not an exact answer is reasonable.

**39,482 + 26,357 = 65,839**  
39,482 + 26,357 is about 40,000 + 26,000 = 66,000  
The sum, 65,839, is reasonable because it is close to the estimate of 66,000.

**8,215 − 5,852 = 3,643**  
8,215 − 5,852 is about 8,000 − 6,000 = 2,000  
The difference, 3,643, is **not** reasonable because it is not close to the estimate of 2,000.

### Essential Question

How do you add whole numbers?

### Visual Learning Bridge

The Jeddah Municipality set a statewide recycling goal. To help meet this goal, Dar Ali Fikr Boys School school students collected newspaper. How many pounds of newspaper did they collect in all?

| Month | Pounds |
|-------|--------|
| March | 358 |
| April | 277 |

Add 358 + 277.  
**Estimate:** 350 + 250 = 600

**Add using partial sums.**

```
  358
+ 277
  15    8 ones + 7 ones
 120    5 tens + 7 tens
+500    3 hundreds + 2 hundreds
 635
```

**Add using the standard algorithm.**

**Step 1** Add ones.  
8 ones + 7 ones = 15 ones. Regroup. 15 ones = 1 ten + 5 ones.

**Step 2** Add tens.  
5 tens + 7 tens + 1 ten = 13 tens. Regroup: 13 tens = 1 hundred + 3 tens.

**Step 3** Add hundreds.  
3 hundreds + 2 hundreds + 1 hundred = 6 hundreds.

The students collected **635 pounds** of newspaper.

Connect adding partial sums to adding using the standard algorithm for addition.

**Convince Me!** Use Structure: In the problem above, when you add partial sums you can add the ones first or the hundreds. Can you do the same when you add using the standard algorithm?

### Solve & Share

Erica's class collected 4,219 bottles for the recycling halalaher. Ana's class collected 3,742 bottles. Leon's class collected 4,436 bottles. How many bottles did the three classes collect? Solve this problem any way you choose.

Just like you did with smaller numbers, you can break up greater numbers by place value to help you add.

**Look Back!** Generalize: Which properties allow you to change the order and grouping of numbers to add? How did you use these properties?

### Essential Question

How do you add greater numbers?

### Visual Learning Bridge

Plans for remodeling a sports stadium include adding an additional 19,255 seats. How many seats will be in the remodeled stadium?

Seats in the original stadium: 20,000 + 4,595 = 24,595

You can use a **variable** to represent the unknown value. The variable *s* represents the total number of seats in the remodeled stadium.

You can use an **algorithm**, which is a set of steps used to solve a math problem.

You can add two or more numbers when you line up the numbers by place value. Add one place at a time.

**Step 1:** Add the ones, then the tens, then the hundreds. Regroup if necessary.

**Step 2:** Add the thousands and the ten thousands. Regroup if necessary.

```
   24,595
+  19,255
   43,850
```

*s* = 43,850  
The remodeled stadium will have **43,850 seats**.

**Step 3:** Use an estimate to check if your answer is reasonable.

25,000 + 19,000 = 44,000  
43,850 is close to the estimate of 44,000, so the answer is reasonable.

**Convince Me!** Construct Arguments: When using the standard algorithm to add 24,595 + 19,255, how do you regroup 1 ten + 9 tens + 5 tens?
