🤔 Current Reflection:

When converting a mixed number to improper fraction, what happens to the whole number part?

🛠️ Quick Reference Toolbox

Mixed → Improper:

Multiply whole × denominator, then add numerator

Example: 2¾ = (2×4+3)/4 = 11/4

Improper → Mixed:

Divide numerator by denominator

Example: 11/4 = 2 remainder 3 = 2¾
