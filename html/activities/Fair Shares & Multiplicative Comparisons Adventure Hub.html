🏗️ Week 7 Culminating Project: "Our Classroom in Comparison"

Driving Question:

How can we use multiplication/division to compare classroom data fairly?

📋 Project Steps:

1️⃣

Choose classroom item

Books, pencils, laptops, desks, etc.

2️⃣

Make 3 multiplicative comparison statements

Use "times as many" language

3️⃣

Solve with both operations

One multiplication, one division

4️⃣

Create bar models + equations

Visual representations for all problems
